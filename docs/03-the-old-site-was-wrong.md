# 3. The old site was wrong

[← Previous](02-getting-our-history-out.md) · [Home](../README.md) · [Next →](04-a-site-that-outlives-me.md)

## The problem

Sponsors read this site, and some of the old content didn't hold up against the club's own
records.

## Checking the content

I didn't treat anything as true just because it was already published. I checked the event
write-ups against the NeuroVR 2024 and 2025 event summaries, the CareXR 2026 summary, the
sponsorship prospectus, judging sheets and Devpost.

| The old site said | What I found |
| --- | --- |
| NeuroVR 2024 was "the first of its kind" | No source backs that up. It was the club's first hackathon. |
| McGillXR is "an organization at McGill University" | The club is independent and open to students from any school |
| A LinkedIn link for an exec member | It went to someone else's profile, so I didn't carry it over |
| A picture for the 2023 orientation Beat Saber booth | It was the game's marketing art, so I replaced it with the club's own Beat Saber photo |

My own draft got the same treatment. It had CareXR's prizes as "$10,150 CAD in cash". The
event summary and the prospectus both say "over $5,000", so I changed it.

Some details needed more digging:

- An old sponsor list mentioned "PECC". It turned out to be the Parc-Ex Curry Collective, a
  food partner.
- NeuroVR 2025 had 152 applications in one document and 143 in another. The forms had
  duplicate submissions, so 152 is the raw count and 143 is most likely unique people. The
  site says "more than 140", which is true either way.

A few facts could not be confirmed or disproved by any club document. Those are flagged in
the project's to-do list so they get checked before anyone repeats them.

## Keeping it accurate

On the old site, sponsors had their own page, separate from the events. Now each sponsor is
recorded on the event it supported, and the sponsors page is built from that: the years,
the "Since 2024" labels and the grouping are all worked out automatically. The site lists 31 organizations, each backed by
a source like an event shirt, a banner, a slide or a Devpost page.
