# 3. The old site was wrong

[← Previous](02-getting-our-history-out.md) · [Back](../README.md) · [Next →](04-a-site-that-outlives-me.md)

**Problem.** Sponsors read this site, and the old content didn't match the club's own
records.

**What I did.** I treated every claim on the old site as something to verify, and checked it
against event summaries, judging sheets, sponsorship decks and Devpost.

| Old site | Records |
| --- | --- |
| "$10,150" in prizes | Over $5,000 |
| "First of its kind" | Our first hackathon |
| "An organization at McGill University" | Independent, open to any school |
| A board member's LinkedIn | A stranger's profile |

Anything I couldn't confirm went on a list instead of onto the site.

**Making it stick.** Sponsors used to be typed in by hand, separately from events, so the two
drifted apart. Now a sponsor is recorded on the event it backed, and the sponsors page is
built from that. The result is 31 organizations, each traceable to a source.
